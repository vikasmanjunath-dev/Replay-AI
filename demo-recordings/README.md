# Demo recording backups

Save the reviewed RELAY AI demo recording in this directory. On macOS, run `scripts/record_demo_backup.sh`; the command writes a timestamped `.mov` file here and does not capture microphone audio. On other platforms, use the platform recorder and save the resulting file here.

Before recording, use the seeded demo account and close any screen that could reveal credentials or unrelated private data. Review the finished clip before sharing. Recordings are excluded from Git because they may be large and contain screen content.
